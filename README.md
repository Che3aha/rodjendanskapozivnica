# Вилењачка пошта — нова зимска позивница

Тара · 6. рођендан · 10. децембар 2026. у 18:00.

„Молимо вас да што пре потврдите долазак.“

## Постављање на GitHub Pages

1. Распакуј ZIP.
2. Постави `index.html` директно у корен GitHub репозиторијума. Ако мењаш претходну позивницу, замени њен `index.html` овим.
3. Settings → Pages → Deploy from a branch → main → / (root) → Save.
4. Отвори линк који GitHub прикаже. Додирни зелени печат на коверти.

## Нова верзија

- Зелена снежна шума и потпуно нова илустрација вилењачког града.
- Пошта, осветљене кућице, снежни кровови и мали вилењаци у граду.
- Три вилењака се крију иза леве, десне и доње ивице екрана, повремено провирују и трепћу. Не блокирају дугмад.
- Коверта са зеленим печатом и анимираним отварањем.
- Музика почиње после додира на коверту и може да се искључи.
- Снег, шљокице и звездана прашина за мишем и на додир.
- Распоред за телефон и рачунар; за смањено кретање анимације се искључују.
- Име, број рођендана, датум, време и четири годишња доба могу да се мењају. Локација, телефон и адреса се не уносе.

## Подели своју позивницу

„Направи своју“ → упиши детаље → „Копирај линк“. Персонализовани линк ради после објављивања на GitHub Pages.

За трајну измену почетне позивнице: „Преузми своју картицу“, преименуј преузету HTML датотеку у `index.html` и постави је у репозиторијум. „Сачувај чаролију“ мења тренутни приказ и линк; не уписује промене у GitHub датотеку.

Потврда доласка је молба у тексту; картица не прикупља пријаве. Дугме за жељу приказује декоративну анимацију и поруку. Нема аналитике, спољних фонтова, музичких сервиса ни инсталације. Све је у једној HTML датотеци.
